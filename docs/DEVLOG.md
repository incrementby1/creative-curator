# Devlog

Development notes for Creative Curator, written as a narrative companion to the
more mechanical changelog.

## 2026-07-21 - Demo-ready creative loop

### What changed

Creative Curator now has a complete end-to-end MVP loop:

1. Intake a brand name, short description, optional reference, and optional goal.
2. Generate a Brand DNA hypothesis with beliefs and tone sliders.
3. Present three divergent creative directions.
4. Let the user reject exactly two directions with structured reasons.
5. Convert those rejections into constraints.
6. Produce a refined direction.
7. Approve the direction and execute a final content artifact.

The backend now treats the workflow as a session-based state machine in
`backend/app/core/hermes.py`. The UI in `client/app/page.tsx` follows the same
state progression, so the demo behaves like a guided creative review rather than
a loose prompt form.

### Why it matters

The important product idea is not just "generate campaign concepts." It is that
the system listens to rejection. The user can say what is wrong with two ideas,
and the app turns that negative signal into constraints for a better final
direction.

That gives the prototype a clearer point of view:

- Creative exploration should be comparative.
- Rejection feedback is useful data, not failure.
- The final output should explain what changed and why.

### Backend notes

The backend was expanded from a thin FastAPI shell into a small orchestration
system:

- `Hermes` coordinates the session lifecycle.
- `DnaAgent` creates the brand hypothesis.
- `DirectionAgent` creates and refines creative territories.
- `CriticAgent` translates rejection labels into constraints.
- `ContentAgent` produces the final caption, SVG layout mock, and rationale.
- `SessionStore` provides in-memory persistence by default, with optional
  Supabase persistence when environment variables are configured.

The current agent behavior is deterministic. That makes the MVP easier to test,
demo, and reason about before plugging in a real LLM provider.

### Frontend notes

The client is a single-page Next.js flow. It is designed around the actual demo
steps instead of a marketing landing page:

- Intake panel
- Brand DNA section
- Direction comparison cards
- Structured rejection controls
- Refined direction review
- Final artifact output

The client proxies `/api/creative/*` to the FastAPI backend through
`client/next.config.ts`, which keeps local development simple.

### Persistence notes

Sessions run in memory by default, so they disappear when the backend restarts.
Supabase can be enabled with:

- `SUPABASE_URL`
- `SUPABASE_SERVICE_ROLE_KEY` or `SUPABASE_ANON_KEY`

The migrations under `supabase/migrations/` create and remove the
`creative_sessions` table. The current Supabase policy is intentionally
demo-friendly and should be tightened before production.

### How to verify

Backend:

```powershell
cd backend
python -m unittest discover -s tests
```

Client:

```powershell
cd client
npm run lint
npm run build
```

Manual demo:

1. Start the backend from `backend/` with `uvicorn app.main:app --reload --env-file .env.local`.
2. Start the client with `npm run dev`.
3. Open `http://localhost:3000`.
4. Create a session, reject two directions, approve the refined direction, and
   execute the final artifact.

### Known limitations

- No authentication or tenant isolation yet.
- Supabase Row Level Security policy is permissive for demo speed.
- Agent outputs are deterministic placeholders, not model-backed generation.
- The rendered SVG artifact is generated by the backend and injected in the UI,
  so production hardening should include stricter sanitization.
- There is no browser-based end-to-end test suite yet.

### Next good steps

1. Add Playwright tests for the happy path and validation states.
2. Replace deterministic agent text with a structured LLM response layer.
3. Add proper auth and per-user session ownership.
4. Lock down Supabase RLS policies.
5. Add CI for backend tests, frontend lint, and frontend build.
6. Add a saved-session browser view so previous creative sessions can be opened.
